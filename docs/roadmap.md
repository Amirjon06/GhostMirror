# Roadmap

This roadmap describes planned technical work. It does not imply release dates.

## Done

- Application scaffold.
- React dashboard.
- FastAPI service.
- SQLite event persistence.
- Alembic migration for the `events` table.
- Event create, list, read, update, and delete API.
- Event export API.
- Event import API.
- Event summary API.
- Event activity API.
- Event source statistics API.
- Event keyword search and filters.
- SQLite FTS5 indexing for event search.
- Clipboard ingestion command.
- Filesystem ingestion command.
- Dashboard integration with the event API.
- Event detail, summary, activity, source, and timeline views.
- Frontend API client tests.
- Frontend component tests.
- Browser smoke test.
- Demo seed command.
- Backend tests for health, events, validation, search, and filters.
- GitHub Actions workflows for backend tests and frontend validation.
- Local environment, setup, development, and check scripts.

## Later

- Add semantic retrieval.
- Add desktop packaging with Tauri.
